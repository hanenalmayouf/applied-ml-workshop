# ابدأ من هنا

مرحبًا بك في ورشة **أسس تعلم الآلة التطبيقي**. خلال خمسة أيام ستتعامل مع مشروع واحد كما يحدث في العمل الحقيقي: سؤال، بيانات، تجربة، تقييم، ثم قرار موثق.

## قبل اليوم الأول

1. ثبّت Python 3.10 أو أحدث.
2. نفّذ أوامر التثبيت الموجودة في الصفحة الرئيسية.
3. شغّل `python scripts/check_environment.py`.
4. افتح `notebooks/student/01_frame_split_baseline.ipynb`.

## طريقة استخدام الدفاتر

- اقرأ سؤال **فكر أولًا** قبل تشغيل الخلية التالية.
- أكمل الخلايا التي تحمل `TODO`.
- سجّل النتيجة والمعنى، لا تكتفِ بالرقم.
- إذا تعطلت، راجع صندوق **مساعدة** قبل فتح الحل.
- نفّذ `Restart Kernel and Run All` قبل التسليم.

## خريطة التعلم

```text
سؤال العمل
   ↓
تحديد صف البيانات والهدف وزمن التنبؤ
   ↓
تقسيم Train/Test + خط أساس
   ↓
تجهيز البيانات داخل Pipeline
   ↓
تدريب ومقارنة تحت Cross-Validation
   ↓
اختيار عتبة تناسب الميزانية
   ↓
اختبار مرة واحدة + Model Card
```

## قاعدة الورشة الذهبية

اسأل عن زمن توفر كل عمود. إذا لم تكن قيمة العمود موجودة لحظة التنبؤ، فهي ليست ميزة مهما رفعت النتيجة.
