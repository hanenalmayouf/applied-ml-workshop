# السلايدات

يبني `scripts/build_course_site.mjs` خمسة عروض HTML من قالب SDAIA Academy المحفوظ في `slides/template/`.

```bash
node scripts/build_course_site.mjs
```

الملفات الجاهزة للعرض موجودة في `docs/slides/`. لا تعتمد الفصول على العرض المرجعي المرفق؛ صُمم محتواها للكورس الحالي، بينما حفظ العرض المرفق داخل `resources/` كمصدر اختياري للمدرب.
