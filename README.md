# أسس تعلم الآلة التطبيقي

مستودع كورس عربي تفاعلي لورشة عملية مدتها خمسة أيام. يتكون من **خمسة Chapters، كل Chapter يمثل يومًا واحدًا**، ولكل يوم عرض HTML مستقل ومعمل أو معملان مرتبطان مباشرة بمحتواه.

> المستوى المستهدف: طالب سنة أولى في تخصص تقني. لا نفترض خبرة سابقة في تعلم الآلة، لكن نحتاج أساسيات بسيطة في Python وpandas.

## ماذا ستبني؟

نموذجًا يتنبأ بالعملاء المحتمل توقفهم عن الطلب خلال 30 يومًا، ثم تحوّل النتائج إلى قرار عملي لحملة احتفاظ محدودة الميزانية. يتطور المشروع يومًا بعد يوم ولا توجد تمارين منفصلة بلا سياق.

## افتح الكورس

افتح [`docs/index.html`](docs/index.html) في المتصفح. ستظهر خمسة أيام، ولكل يوم:

- زر **عرض الفصل** لفتح السلايدات التفاعلية.
- زر **المعمل A** و**المعمل B** في الأيام 1 إلى 4.
- مشروع متكامل في اليوم 5.

## الفصول الخمسة

| اليوم | الفكرة الرئيسية | التطبيق | الناتج |
|---|---|---|---|
| Chapter | موضوع اليوم | السلايدات | التطبيق |
|---:|---|---|---|
| 1 | من المشكلة إلى أول نموذج | ML المناسب، أنواع المسائل، التسرب، التقسيم، baseline، regression | Lab 1A + Lab 1B |
| 2 | التصنيف وبناء Pipeline | الاحتمالات، confusion matrix، Logistic، Decision Tree، overfitting، preprocessing | Lab 2A + Lab 2B |
| 3 | تقييم النموذج وتحسينه | PR-AUC، CV، threshold، slice analysis، ensembles، importance | Lab 3A + Lab 3B |
| 4 | اكتشاف الأنماط واختيار النموذج | K-Means، اختيار k، PCA، random search، test مرة واحدة | Lab 4A + Lab 4B |
| 5 | تنفيذ المشاريع وعرضها | Dataset من اختيار الفريق، milestones، rubric، model card | Capstone + تقييم وعروض |

## ابدأ خلال دقائق

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

ابدأ من [`course/00_start_here.md`](course/00_start_here.md)، ثم استخدم روابط الأيام داخل صفحة الكورس. الحلول موجودة في `notebooks/solutions/` للمدرب والمراجعة الذاتية.

## هيكل المستودع

```text
docs/index.html          الصفحة الرئيسية للكورس
docs/slides/             خمسة عروض HTML جاهزة للفتح
slides/template/         قالب SDAIA Academy المحفوظ
labs/day1 ... day5/      معامل مرتبة حسب أيام الكورس
course/                  خطة التنفيذ، دليل المدرب، والتقييم
data/                    بيانات منافذ وقاموس البيانات
notebooks/solutions/     دفاتر الحلول المكتملة
src/manafeth/            دوال قابلة لإعادة الاستخدام
tests/                   اختبارات سلامة سريعة
templates/               قوالب التأطير وبطاقة النموذج
```

## مبادئ الورشة

1. نحدد القرار قبل اختيار الخوارزمية.
2. نفصل مجموعة الاختبار مبكرًا ولا نفتحها حتى النهاية.
3. نقارن كل نموذج بخط أساس بسيط.
4. نضع كل المعالجة داخل `Pipeline`.
5. نختار المقياس والعتبة حسب تكلفة القرار.
6. نوثق حدود النموذج بوضوح.

جميع Labs الأيام الأربعة الأولى مبنية على بيانات «منافذ». في اليوم الخامس يحضر كل فريق Dataset جديدة معتمدة ليطبق دورة العمل باستقلالية؛ توجد ملفات احتياطية في الحزمة عند الحاجة.
